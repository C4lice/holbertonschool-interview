# double_circular_linked_list

Holberton School interview preparation project.

## Description

This project implements basic operations on a **doubly circular linked
list** in C:

- `add_node_end`: adds a new node at the end of the list
- `add_node_begin`: adds a new node at the beginning of the list

## Files

- `list.h`: header file containing the `List` structure and the function
  prototypes
- `0-add_node.c`: source file containing `add_node_end` and
  `add_node_begin`

## Compilation

```bash
gcc -Wall -Wextra -Werror -pedantic 0-main.c 0-add_node.c -o a.out
```
